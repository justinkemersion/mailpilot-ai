# MailPilot dashboard screenshots

Curated marketing screenshots for README and Flux showcase materials.

## Capturing

1. Run the web app locally or on a staging host.
2. For a consistent public demo, set `MAILPILOT_DEMO_MODE=true` and `NEXT_PUBLIC_DEMO_BANNER=true` (see `mailpilot-web/README.md`).
3. Sign in, open `/dashboard/overview`, and capture at **1280×800** (desktop) and **390×844** (mobile).
4. Save PNGs here with descriptive names, for example:
   - `overview-desktop.png`
   - `overview-mobile.png`
   - `activity-desktop.png`
   - `accounts-desktop.png`

Do not commit screenshots that contain real Gmail addresses, tokens, or production user data unless intentionally redacted.
